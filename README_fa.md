# rostam — ربات رسانه و ابزار تلگرام

[English](README.md) · **فارسی**

رباتی چندزبانه برای تلگرام (نوشته‌شده با Rust، کریت `ros-telegram-bot`) — رابط
کاربری به فارسی، انگلیسی و ایتالیایی (با دستور `/language` جابه‌جا می‌شود) — که یک
جعبه‌ابزار رسانه‌ای را در دل خود دارد: دانلود یوتیوب، جداسازی صدا (وکال/موسیقی)،
تبدیل گفتار به متن، حذف نویز صدا، بزرگ‌نمایی تصویر، حذف واترمارک، فشرده‌سازی PDF،
جست‌وجوی IP و بسته‌های ایموجی سفارشی — همه پشت یک رابط رتبه‌بندی‌شده/پولی. کارهای
سنگینِ پردازنده در سرویس‌های جانبیِ پایتون اجرا می‌شوند که با یک CPU-broker مبتنی
بر Redis هماهنگ می‌گردند.

---

## نصب سریع (روی سرور خام)

روی یک سرور تازه‌ی **Debian/Ubuntu** یا **Arch**، یک دستور همه‌چیز را برپا می‌کند:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mmahdi-sz/rostam/master/install.sh)
```

نصب‌کننده به‌صورت خودکار با `sudo` بالا می‌آید، مخزن را در `/opt/rostam` کلون می‌کند
و کل پشته را برپا می‌سازد. **idempotent** است — اجرای دوباره‌اش امن است. هنگام نصب،
`BOT_TOKEN` (و برای Bot API محلی، `api_id`/`api_hash` تلگرام) را از شما می‌پرسد.

> نصب‌کننده حدود ۴.۲ گیگابایت مدل به‌علاوه‌ی یک مدل ASR حدود ۱.۵ گیگابایتی دانلود
> می‌کند و ربات Rust (و اختیاراً سرور Telegram Bot API) را از سورس می‌سازد — اجرای
> اول کمی طول می‌کشد و به حدود ۱۲ گیگابایت فضای خالی نیاز دارد.

### گزینه‌های نصب‌کننده

```
--dir <path>      محل نصب (پیش‌فرض /opt/rostam)
--branch <name>   شاخه‌ی گیت (پیش‌فرض master)
--skip-bot-api    از ساختن سرور Telegram Bot API محلی صرف‌نظر کن
--skip-asr        سرویس ASR (پورت ۸۷۶۵) را نصب نکن
--skip-firefox    فایرفاکس (رفرش‌کننده‌ی cookie-pool) را نصب نکن
--fresh           از صفر دوباره کلون/بیلد کن
```

## چه چیزهایی نصب می‌کند

| لایه | جزئیات |
|---|---|
| **بسته‌های سیستمی** | git، curl، unzip، tar، ffmpeg، ghostscript، PostgreSQL، Redis، پایتون ۳ (+venv)، ابزارهای بیلد، cmake، فایرفاکس |
| **Rust** | از طریق `rustup` (نسخه‌ی ادیشن ۲۰۲۴ به rustc ≥ 1.85 نیاز دارد) |
| **deno** | در `/opt/deno` — به فلگ `--js-runtimes` در yt-dlp برای چالش‌های جاوااسکریپت یوتیوب پاس داده می‌شود |
| **yt-dlp** | آخرین باینری استاتیک → `/usr/local/bin/yt-dlp` |
| **مدل‌ها (~۴.۲ گیگابایت)** | Vosk STT (فارسی/انگلیسی)، Moebius ONNX (واترمارک)، DeepFilterNet، Real-ESRGAN، `libvosk.so` → `files/` |
| **PostgreSQL** | دیتابیس `ros_telegram_bot` را می‌سازد (ربات جدول‌های خودش را در اولین اجرا می‌سازد) |
| **خودِ ربات** | `cargo build --release` → `rostam.service` |
| **سرویس separation** | جداسازی وکال/موسیقی (پورت ۶۵۸۹)، مدلش را خودش دانلود می‌کند |
| **سرویس ASR** | تبدیل گفتار به متن Nemotron (پورت ۸۷۶۵)، مدل ~۱.۵ گیگابایتی در `/opt/asr_model` |
| **surge** | دیمِنِ دانلودمنیجرِ موازی [SurgeDM/Surge](https://github.com/SurgeDM/Surge) (پورت ۱۷۰۰)، باینری آخرین ریلیز → `surge.service` |
| **Telegram Bot API محلی** | از سورس tdlib بیلد می‌شود (پورت ۸۰۸۱) — سقف آپلود را به ۲ گیگابایت می‌رساند |

## معماری

> نمودار به‌صورت اصلی (انگلیسی/ASCII) نگه داشته شده است.

```
                       ┌──────────────────────────┐
   Telegram  ─────────►│  local Bot API  :8081     │  (2 GB uploads)
                       └────────────┬─────────────┘
                                    │
                          ┌─────────▼─────────┐
                          │  rostam (Rust)    │
                          │  target/release/  │
                          └───┬───────┬───┬───┘
             ┌────────────────┘       │   └─────────────────┐
      ┌──────▼──────┐          ┌──────▼──────┐       ┌──────▼───────┐
      │ PostgreSQL  │          │   Redis     │       │  sidecars    │
      │  :5432      │          │   :6379     │◄──────│  CPU broker  │
      └─────────────┘          └─────────────┘       └──────┬───────┘
                                              ┌─────────────┼─────────────┐
                                     ┌────────▼───┐  ┌───────▼────┐ ┌──────▼─────┐
                                     │ separation │  │    ASR     │ │  surge dl  │
                                     │   :6589    │  │   :8765    │ │   :1700    │
                                     └────────────┘  └────────────┘ └────────────┘
```

ربات به Postgres، Redis و سرویس‌های جانبی **با تنبلی (lazy)** وصل می‌شود — هیچ‌کدام
هنگام راه‌اندازی الزامی نیستند. اگر Postgres پایین باشد، ربات با پایداری غیرفعال کار
می‌کند؛ اگر یک سرویس جانبی پایین باشد، فقط همان قابلیت پیام «سرویس در دسترس نیست»
می‌دهد. تنها الزامِ سختِ راه‌اندازی، `BOT_TOKEN` است.

## قابلیت‌ها

دانلود یوتیوب (پی‌وال روی کیفیت/زیرنویس/ترافیک) · جداسازی وکال/موسیقی · تبدیل گفتار
به متن (Vosk + Nemotron ASR) · حذف نویز صدا (DeepFilterNet) · بزرگ‌نمایی تصویر
(Real-ESRGAN) · حذف واترمارک (Moebius ONNX، درون‌فرایندی) · فشرده‌سازی PDF
(Ghostscript) · دانلود مستقیمِ سریع و موازیِ لینک (Surge) · جست‌وجوی IP · بسته‌های
ایموجی سفارشی · رتبه‌ها و پی‌وال · سیستم دعوت (رفرال) · پنل آمار ادمین.

دستورها: `/start`، `/panel`، `/language`، `/rank`، `/emoji`، `/se`.

## پیکربندی (`.env`)

نصب‌کننده فایل `.env` را از روی `.env.example` می‌سازد. مقادیر کلیدی:

| متغیر | کاربرد |
|---|---|
| `BOT_TOKEN` | **الزامی** — از @BotFather |
| `ADMIN_USER_ID` | آیدی تلگرامِ دارای دسترسی پنل ادمین + مدیریت کش ایموجی |
| `DATABASE_URL` | `postgres://postgres:postgres@localhost:5432/ros_telegram_bot` |
| `REDIS_URL` | پیش‌فرض `redis://127.0.0.1:6379` |
| `BOT_API_BASE_URL` | `http://127.0.0.1:8081` (Bot API محلی؛ خالی → API رسمی، سقف ۲۰ مگابایت) |
| `DENO_PATH` | مسیر باینری deno (پیش‌فرض `/opt/deno/bin/deno`) |
| `IPINFO_TOKEN`، `ABUSEIPDB_KEY` | غنی‌سازی اختیاریِ جست‌وجوی IP |

همه‌ی مسیرهای قابلیت‌ها (`files/models/*`، `config/i18n.json`) **نسبت به دایرکتوری
کاریِ ربات** (`/opt/rostam`) حل می‌شوند، پس یونیت systemd مقدار `WorkingDirectory`
را متناسب با آن تنظیم می‌کند.

## به‌روزرسانی

```bash
cd /opt/rostam
git pull
cargo build --release
sudo systemctl restart rostam
```

یا نصب‌کننده را دوباره اجرا کنید (idempotent است) تا مدل‌ها و سرویس‌های جانبی هم
تازه شوند.

## راه‌اندازی دستی / توسعه

```bash
git clone https://github.com/mmahdi-sz/rostam.git && cd rostam
cp .env.example .env          # BOT_TOKEN را پر کن
cargo build                   # بیلد دیباگ (به files/runtime/libvosk.so نیاز دارد)
./target/debug/ros-telegram-bot
```

دستور `cargo build` به `files/runtime/libvosk.so` لینک می‌شود (به `build.rs` نگاه
کنید)، پس اسِت‌های مدل/رانتایم باید موجود باشند — یک‌بار `install.sh` را اجرا کنید
تا آن‌ها را بگیرد، یا دستی قرارشان دهید.

## کاستی‌های شناخته‌شده

- **دیمِن `surge` (پورت ۱۷۰۰)** از [SurgeDM/Surge](https://github.com/SurgeDM/Surge)
  نصب می‌شود و ربات را با یک فایل توکنِ متعلق به روت
  (`/root/.local/state/surge/token`) احراز هویت می‌کند. برای همین هم دیمِن و هم ربات
  با کاربر **root** اجرا می‌شوند تا آن توکن را مشترک داشته باشند — اجرای ربات با
  کاربر غیرروت باعث می‌شود `tools:surge` خطای ۴۰۱ بدهد.
- **cookie-pool فایرفاکس** به یک X display نیاز دارد؛ روی سرور بدون گرافیک،
  رفرش‌کننده‌ی کوکی یوتیوب اجرا نمی‌شود (یوتیوب بدون کوکی هم کار می‌کند). برای فعال
  کردنش `COOKIE_REFRESH_DISPLAY` را ست کنید / زیر Xvfb اجرا کنید.
- **باینری `deep-filter`** از ریلیزهای DeepFilterNet گرفته می‌شود؛ اگر آن فایل در
  دسترس نباشد، حذف نویزِ STT افت می‌کند (خودِ STT پایه همچنان کار می‌کند).
- **Bot API محلی** به `api_id`/`api_hash` تلگرام از
  <https://my.telegram.org> نیاز دارد؛ بدون آن، از `--skip-bot-api` استفاده کنید
  (API رسمی، سقف آپلود ۲۰ مگابایت).
